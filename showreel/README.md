# CLAUDE — Motion Reel 2026

A 15-second, 1920×1080 @ 60 fps motion design showreel. Every frame and every sound is generated by code: no stock footage, no samples, no keyframe software.

**Watch:** [`showreel.mp4`](showreel.mp4) · **Play it live:** serve this folder and open `index.html`

## The cut

The track runs at 128 BPM, so one bar is 1.875 s and eight bars come to exactly 15 s. Every cut, hit and transition lands on the grid.

| Bar | Time | Act | Techniques |
|---|---|---|---|
| 1 | 0.00 | **Cold open** | Squash & stretch, anticipation, impact rings, a dot that becomes a keyframe timeline, a line wipe to full frame |
| 2 | 1.88 | **Kinetic type**: *EVERY / FRAME / ON / PURPOSE.* | Masked letter stagger, blur-zoom inside an animated AE-style bounding box, spring + echo trails, slice-offset type. The period becomes an iris |
| 3 | 3.75 | **Shape language** | 16×9 grid with radial stagger waves: circle → diamond → outline, then a vortex implosion into one point |
| 4 | 5.63 | **3D / SDF** | Raymarched chrome/iridescent metaballs (WebGL2 shader), studio env lighting, orbiting camera, HUD reticle, riser push-in |
| 5 | 7.50 | **The drop** | 9,000 particles explode and resolve into the wordmark, with procedural motion streaks |
| 6 | 9.38 | **Systems** | Responsive split-screen with layout morphs: data viz, UI micro-interactions, a hypnotic loop, type on a path |
| 7 | 11.25 | **Velocity** | Star iris into a curved 3D tunnel, extruded type on every beat, glitch, barrel distortion |
| 8 | 13.13 | **End card** | Silence, then the hit. Spring-assembled wordmark, light sweep, and the orange dot returns home |

Post stack (fragment shader): bloom built from the mip chain, chromatic aberration, camera shake, zoom punches, glitch bands, vignette, and film grain. All of it is driven by a single `post(t)` timeline.

## How it's built

- `index.html`: the renderer. Canvas2D draws the layouts, and WebGL2 raymarches the 3D act and composites everything through the post pass. Each frame is a **pure function of `t`**, so frames can be rendered out of order and in parallel. Opened in a browser, it plays in real time with sound.
- `audio.py`: the soundtrack, synthesized with NumPy/SciPy. Kick, clap, hats, sidechained bass, pads, arps and supersaw stabs, plus sound design (whooshes, risers, glitches, UI clicks, pitched keyframe ticks) placed on the same timestamps as the picture.
- `render.mjs`: drives headless Chromium with Playwright, 4 workers in parallel, and pipes the PNG frames into ffmpeg. It then concatenates the segments and muxes in the audio.

```bash
pip install numpy scipy            # audio
npm i playwright                   # renderer
python3 audio.py                   # → soundtrack.wav
FFMPEG=/path/to/ffmpeg node render.mjs          # → showreel.mp4
node render.mjs --stills 2.1,6.2,8.95           # review individual frames
```
